What is running here?

The task state, filtering, undo, flex layout, hit testing, scrolling, drag gestures and scene data run in MoonBit. A browser host paints the same scene's rectangles and text to a Canvas 2D viewport and projects visible cards to accessible buttons.

Text uses the browser's system font. This is an experimental browser slice: full text editing and IME, a general accessibility adapter, WebGPU and cross-browser qualification remain open. The interaction lab exercises clipboard, committed input, renderer restoration and the existing migration fixture.
